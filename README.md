### 3️⃣ Используйте приложение

1. Откройте браузер на **http://localhost:8000**
2. Нажмите **"Регистрация"**
3. Введите:
   - Email (любой)
   - Имя пользователя
   - Пароль
4. Нажмите **"Зарегистрироваться"**
5. Играйте! Ваши данные сохраняются в Supabase

## Что сохраняется?

✅ **Баланс** - обновляется после каждой ставки  
✅ **История ставок** - последние 6 ставок с результатом  
✅ **Профиль** - email, имя пользователя, дата регистрации

## Если что-то не работает

### ❌ "CORS Error"
→ Убедитесь что используете `http://localhost`, не `file://`

### ❌ "Таблицы не найдены"
→ Запустите SQL из `supabase-setup.sql` в Supabase

### ❌ "Email уже зарегистрирован"
→ Используйте другой email или удалите пользователя в Supabase

### ❌ Данные не сохраняются
→ Откройте DevTools (F12) → Console, проверьте ошибки
