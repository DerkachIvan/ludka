## 2. Создание таблиц в Supabase

1. Откройте [app.supabase.com](https://app.supabase.com)
2. Выберите ваш проект
3. Перейдите в **SQL Editor** слева
4. Нажмите **New Query**
5. Скопируйте весь код из файла `supabase-setup.sql`
6. Вставьте в редактор
7. Нажмите **Run** (Ctrl+Enter)

Это создаст таблицы:
- `users` - профили пользователей
- `bet_history` - история ставок

---

## 3. Включение Email/Password Authentication

1. В Supabase откройте **Authentication** слева
2. Перейдите в **Providers**
3. Убедитесь, что **Email** включен (должен быть по умолчанию)
4. Сохраните

## 5. Как работает интеграция

### При регистрации:
1. Пользователь вводит email, пароль, имя пользователя
2. Создается аккаунт в Supabase Auth
3. Создается профиль в таблице `users` с начальным балансом $100

### При логине:
1. Пользователь вводит email и пароль
2. Загружается баланс из таблицы `users`
3. Загружается история последних 6 ставок

### При каждой ставке:
1. Баланс сохраняется локально (localStorage)
2. И одновременно отправляется в Supabase
3. История ставки сохраняется в таблице `bet_history`

### При выходе:
1. Данные сохраняются в Supabase
2. Баланс и история восстанавливаются из localStorage для локального использования

## 6. Настройки безопасности (RLS)

Все таблицы защищены Row Level Security:
- Пользователи видят только свои данные
- Пользователи не могут видеть данные других
- Административные операции защищены

## 7. Решение проблем

### Проблема: "CORS error" или "Connection refused"
**Решение:** 
- Убедитесь, что вы используете HTTP сервер (http://localhost, не file://)
- Проверьте что правильно скопировали Project URL и API key

### Проблема: "Таблицы не найдены"
**Решение:** 
- Перейдите в SQL Editor в Supabase
- Запустите код из `supabase-setup.sql`

### Проблема: "Email уже зарегистрирован"
**Решение:** 
- Используйте другой email или восстановите пароль

### Проблема: "Сохранение данных не работает"
**Решение:** 
- Откройте Developer Tools (F12)
- Посмотрите Console на ошибки
- Проверьте что пользователь залогинен (должны видеть его email в углу)
